# 3.6 Your business: what would yours watch? (3:35, 15 min) and wrap (3:50, 10 min)

!!! abstract "Goal"
    Leave with one concrete agent you could build at work on Monday.

## Design it at your table (10 min)

Each table picks one thing their own company depends on and fills in this card together:

| Question | Your answer |
| --- | --- |
| What does the business depend on? (a SaaS app, a supplier portal, a store's payment lane, a plant line) | |
| Which Cisco data shows it is healthy or not? | |
| Which **non-Cisco** source would you plug in? (ticketing, CMDB, status page, weather, power, shift roster) | |
| What makes it critical, and when? (hours, money, safety, SLA) | |
| Who should be woken, and when should nobody be? | |
| The one safe action the agent may take after approval | |
| What it must never do | |

## Share (5 min)

Three or four tables share their card with the room in one minute each.

## Wrap

- **Take-home kit:** the Lab Kit (broker, MCP server starter and solution, OpenAPI specs, prompts,
  lane triage skill, tests). Everything is Python standard library; no packages to install.
- **Your work in the tenant:** your Canvas boards, Studio agent and integrations stay until the
  proctors reset the tenant after the session. Copy your prompts and manifest text if you want them.
- **Survey:** please fill it in before you leave. It decides what we build next.

Thank you, and sleep well.
