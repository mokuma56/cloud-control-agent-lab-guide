# LTROPS-2623 Build a Network Agent in Cisco Cloud Control That Troubleshoots Anything While You Sleep

Student guide for the Cisco Live EMEA 2027 lab *Build a Network Agent in Cisco Cloud Control That
Troubleshoots Anything While You Sleep* (4 hours, 30 seats).

Published at **https://mokuma56.github.io/cloud-control-agent-lab-guide/** from the `gh-pages` branch.

Publish an update: `mkdocs gh-deploy --strict` (builds the site and pushes it to `gh-pages`).

Build locally:

```bash
pip install -r requirements.txt
mkdocs serve        # http://127.0.0.1:8000
```

Seat tokens, lab URLs and proctor procedures are deliberately not in this repository; they are on
the printed seat cards and in the proctor runbook that ships with the lab kit.
